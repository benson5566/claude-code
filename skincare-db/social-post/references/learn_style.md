# P1 — 風格學習框架（保養帳號版）

## 分析步驟

1. 用 Chrome MCP 打開使用者的 Facebook
2. 爬最近 20 篇公開貼文，記錄每篇的：
   - 字數 / 段落數
   - 標點偏好（感嘆號、省略號、句號頻率）
   - Emoji 類型與位置
   - 開頭第一句句型（問句 / 場景切入 / 直接論點）
   - 收尾方式（邀請互動 / 金句 / 直接結尾）
   - 是否用條列式
   - 常出現的語氣詞（好吧、其實、真的、欸、哈）
3. 分析保養領域特有的聲音特徵：
   - 如何稱呼讀者（你/大家/姐妹們/寶子）
   - 引用研究時的態度（「研究顯示」vs「有研究說」vs「幹我看到一個論文」）
   - 對廣告 / 業配的態度（明確標示 / 完全不做 / 歡迎合作）
4. 判斷整體風格類型（A親切 / B冷靜 / C故事 / 混合型）
5. 找 2-3 篇代表貼文作為 few-shot 範例
6. 覆寫 `style_profile.md`

## 輸出格式（寫入 style_profile.md）

覆寫所有「待補」欄位，在「代表性原文」段落貼 2-3 篇真實貼文原文作為 few-shot。
